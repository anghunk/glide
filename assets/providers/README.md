本目录包含 Glide 的翻译、OCR 渠道与可选 AI 品牌图标。除网易有道外，SVG 下载自 [LobeHub Icons](https://icons.lobehub.com/) 官方维护的静态资源包，不引入 React 或其他前端依赖。

- 上游仓库：[lobehub/lobe-icons](https://github.com/lobehub/lobe-icons)
- 固定资源版本：`@lobehub/icons-static-svg@1.102.0`
- 下载日期：2026-11-12；OCR 与新增 AI 图标补充于 2026-11-13
- 下载入口：`https://unpkg.com/@lobehub/icons-static-svg@1.102.0/icons/<文件名>`
- 许可：上游 MIT，完整原文保留在 [LICENSE](LICENSE)，并随 SVG 嵌入应用。
